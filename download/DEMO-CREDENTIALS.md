# SpagKing — Demo Credentials

## Demo Login

Open the application at `http://localhost:3000`

The splash screen plays for ~6 seconds (press any key to skip).

After the splash, the **SpagKing Landing Page** appears.
Click **"Order Now"** to access the Demo Login screen.

## 9 Demo Roles

Click any role card to instantly enter that role's dashboard.
No password required — this is a demo environment.

| # | Role | What You See | Key Demo Flow |
|---|------|-------------|-------------|
| 1 | **Customer** | Customer app: home, menu, cart, checkout, tracking, loyalty, community, profile | Order a meal → checkout → live tracking |
| 2 | **Cashier** | POS Terminal: product grid, ticket, payments, shift management | Add items to ticket → charge → close shift |
| 3 | **Kitchen** | POS Terminal + Inventory (kitchen tickets + stock access) | View ticket → send to kitchen → check stock |
| 4 | **Manager** | Executive Dashboard + all operational modules | View KPIs → check reports → review staff |
| 5 | **Inventory** | Inventory Dashboard: stock, suppliers, POs, waste, expiry | View low stock → create PO → log waste |
| 6 | **HR Officer** | Staff & HR: directory, attendance, shifts, leave, payroll, training, performance, disciplinary | Clock in staff → approve leave → review performance |
| 7 | **Rider** | Delivery Dashboard: live map, riders, zones, metrics | View active deliveries → check rider performance |
| 8 | **Administrator** | Admin Panel: branches, users, roles, taxes, settings, tables, integrations, audit | View branches → manage roles → check audit log |
| 9 | **CEO** | Executive Dashboard + Reports + CRM + Admin access | View today's sales → check branch ranking → review P&L |

## Quick Demo Path

**For a 10-minute demo:**
1. Customer → Order a meal → Checkout → Live Tracking (3 min)
2. Cashier → POS walk-in order → Charge (2 min)
3. CEO → Executive Dashboard (2 min)
4. Inventory → Low stock alerts (1 min)
5. HR → Staff directory + disciplinary (2 min)

## Demo Data

- 250 customers with Nigerian names, addresses, and order history
- 60 meals across 7 categories (Spaghetti, Rice, Shawarma, Burgers, Drinks, Soups, Desserts)
- 12 delivery riders with live status
- 35 employees across all departments
- 18 suppliers with ratings and outstanding balances
- 700 orders with realistic statuses
- 4 branches: Lekki Phase 1, Maroko/Oniru, Surulere, Lokoja

## Theme

Toggle between Dark / Light / System using the theme toggle in the
top-right corner of any screen. The preference persists across reloads.
